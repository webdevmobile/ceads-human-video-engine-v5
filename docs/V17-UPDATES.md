# V17 — Vidéos inline, barres fixes et garantie compacte

- Toutes les zones vidéo jouent désormais directement dans leur cadre : aucun popup de lecture.
- La VSL du Hero conserve son comportement inline et reçoit un message discret invitant à regarder la vidéo jusqu’au bout.
- La launch bar est fixe sur desktop, tablette et mobile.
- Le header est fixe uniquement sur desktop ; il reste dans le flux sur tablette et mobile.
- Le visuel de garantie est plus compact sur desktop, tablette et mobile.
- Les contrôles natifs des vidéos directes restent utilisables après le démarrage.
