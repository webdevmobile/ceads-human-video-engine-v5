# Checkout Chariow

Lien actuellement branché :

`https://lumina-ebooks.mychariow.com/laverie-domicile/checkout`

Tous les CTA principaux portant la classe `js-checkout` sont reliés automatiquement à ce lien par `assets/js/app.js`.

Pour remplacer le checkout plus tard :

1. ouvrir `assets/js/config.js` ;
2. modifier uniquement `checkoutUrl` ;
3. enregistrer puis redéployer le site.

Aucune API CinetPay ni backend de paiement n'est utilisé dans cette version.
