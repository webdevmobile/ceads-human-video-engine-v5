# V13 — Guide utilisateur sous les vidéos

Une consigne légère est désormais injectée automatiquement sous chaque zone vidéo :

- cliquer sur la miniature ou le bouton Play pour visionner ;
- activer le son avec l’icône du lecteur si nécessaire.

La même indication sonore apparaît sous le lecteur lorsqu’une vidéo s’ouvre dans la modal.
